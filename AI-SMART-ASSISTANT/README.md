# AI Smart Assistant 🤖

AI Smart Assistant is a web-based application built with Python Flask, HTML, CSS, JavaScript, and SQLite.

## Features
- Interactive chat interface
- User registration and login
- Send and receive messages
- Store conversations
- Delete conversations
- Dark mode and light mode
- Responsive design

## Technologies
- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite

## Run Locally

Install dependencies:

pip install -r requirements.txt

Run the application:

python app.py

Open http://127.0.0.1:5000 in your browser.
